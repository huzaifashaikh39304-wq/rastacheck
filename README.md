# RastaCheck

RastaCheck is an open-source civic pothole-reporting web app built for commuters and residents across Dakshina Kannada and Udupi. It allows citizens to log road damage with landmarks, severity levels, and photos so dangerous stretches on NH-66, state highways, and city roads are documented publicly.
